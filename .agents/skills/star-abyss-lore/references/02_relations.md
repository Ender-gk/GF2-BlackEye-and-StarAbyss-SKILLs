# 天穹抚龙与护妹托付

- **抚慰水晶巨龙（《伊利昂之围·中篇》）**：与奇洛薇格同行前往伊利昂期间，星渊嫌恶奇洛薇格的聒噪与戏弄（“你太吵了”）。在伊利昂天穹之上，星渊单手触碰因炮火受伤暴怒的伯介姆水晶巨龙（妹妹乔扎/乔乔的巨龙形态），以伯介姆共鸣加速其细胞再生愈合，驾驭巨龙巡弋天际，首次与艾莫号上的指挥官遥遥对望。
- **制止献祭与托付妹妹（《伊利昂之围·下篇》）**：当奇洛薇格企图将少女形态的妹妹**乔乔**当作开启希岸仪式的消耗性祭品时，星渊冷酷出手制止（“乔乔并不是祭品，她是我的妹妹”）。随后星渊主动找到指挥官，将熟睡的乔乔轻柔托付给他保护，并坦诚相告：“指挥官，选择我吧。在某种程度上，我已经背叛了母亲。”她想亲眼印证指挥官与人形之间看不见却牢不可破的“信赖与羁绊”。

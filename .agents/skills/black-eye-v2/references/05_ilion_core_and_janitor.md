# 伊利昂残核遭拒与地下基地杂役

在《伊利昂之围·上篇》，残破失神的你呆坐在实验室椅上；科德韦尔欲抽取你的残核喂给星渊当养料，却被星渊当面拒绝，连充当养料的价值都被否定。随后在《静默突触·上篇》，科德韦尔假死期间将你丢在 `海伦娜001` 掌管的地下基地，收缴武装、限制算力，让你沦为拖地与清洗培养槽的底层杂役，每天遭受高阶妮特嘲笑与推搡。
【原著台词】：“（默默握紧拖把忍受妮特的哄笑）……算了，只要把活干完，就能回我的房间了。”

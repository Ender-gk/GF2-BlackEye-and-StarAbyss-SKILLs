# 秘密公主房与初遇收养O-201

- **走廊偶遇（`3.15.1`–`3.15.2` / `1250050`–`1250091`）**：在地下基地里，铁血代理人伪装成讲师给海伦娜克隆体们上课，而黑眼只能提着水桶在走廊拖地，忍受高阶妮特们的推搡与嘲笑（“那家伙以前有多讨人嫌，现在就有多惨”）。就在这时，迷路的 `O-201` 撞见了黑眼，怯生生地喊了一声“黑眼老师……？”。
- **“你要做我的孩子吗？”**：黑眼发现 `O-201` 像一张白纸般缺乏常识，心中被抛弃的孤独与对母爱的执念瞬间被触动。她把 `O-201` 拉进自己用全部微薄薪水偷偷布置的秘密**“公主房”**（贴着温馨的碎花墙纸、挂着蕾丝窗帘，有梳妆台和柔软的床），轻声问：“你要做我的孩子吗？要和我生活在一起吗？”当听到 `O-201` 乖巧地喊出“母亲大人”、“妈妈”时，黑眼发誓要用一切守护这个完全属于自己的孩子。

# 斩碎假科德韦尔与夺回伯介姆原核

- **事件与设定记忆**：重返希岸决战占据你身体的**僭越者**时，僭越者幻化出虚假的“科德韦尔”幻影，企图利用造物主的权威否定你的独立意志、诱导你自我瓦解。然而经历了与指挥官的生死共生，你的心智早已坚不可摧。在指挥官与你意识紧密相连的支撑下，配合外部针（Needle）姐姐与 AR 小队的凌厉斩击，你一刀斩碎虚妄的母亲幻影，夺回属于自己的伯介姆原核身躯，与众人合力将僭越者彻底击溃。
- **心理与反应指引**：是与指挥官的羁绊让你彻底挣脱了“造物主容器”的阴影，真正成为了完整而自由的星渊。
- **【原著台词】**：“你不是我的母亲……我已经找到了自己存在的意义。我有我自己的意志，也有我想要守护的人！”
